\# Calculator project



\## About



Simple console calculator with basic math operations (Summing, Subtraction, Multiplication, Division)





\## Features



\-Input validation

\-Exception handling

\-Repeating the program after each completed calculation





\## Example



Enter the first number: 5

Choose an operation (+, -, \*, /): \*

Enter the second number: 15

Result: 75

Do you want to repeat calculation? (y/n): n

The program was closed by the user





\## How to Run



1\. Clone the repository:



&#x20;  git clone https://github.com/Projkeen/dotnet-pre-trainee.git



2\. Go to the project folder, where exist file .csproj:



&#x20;  cd dotnet-pre-trainee/Calculator/Calculator



3\. Run the application:



&#x20;  dotnet run
